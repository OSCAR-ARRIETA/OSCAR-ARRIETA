## 👨‍💻 Sobre mí

Soy **Ingeniero en Sistemas Energéticos y Redes Inteligentes**, egresado del **Instituto Politécnico Nacional (IPN)**. Mi perfil profesional integra la ingeniería eléctrica, la automatización industrial, la programación y las energías renovables.

Tengo experiencia en instalaciones eléctricas industriales y participación en proyectos de automatización de plantas de tratamiento de aguas residuales mediante PLC Delta, interfaces HMI y sistemas de control.

Este portafolio reúne proyectos de ingeniería, programación, documentación técnica, diagramas eléctricos y diseños desarrollados para resolver problemas reales.

- ⚙️ Automatización industrial y control de procesos.
- 💻 Programación de PLC, lógica Ladder y desarrollo de interfaces HMI.
- 🖥️ Sistemas de supervisión, monitoreo y adquisición de datos.
- ⚡ Instalaciones eléctricas industriales, tableros y cableado.
- ☀️ Diseño y simulación de sistemas fotovoltaicos.
- 🔋 Sistemas de almacenamiento energético BESS y seguridad eléctrica.
- 🚁 Desarrollo de prototipos para inspección de infraestructura eléctrica.
- 🌐 Integración de sensores, sistemas embebidos e IoT.

## 🚁 Innovación e inspección inteligente

### 04. Dron para inspección de infraestructura eléctrica

Propuesta de diseño e integración de un dron para la inspección de sistemas fotovoltaicos mediante visión térmica, posicionamiento GPS y sensores ambientales.

El objetivo es identificar posibles puntos calientes (*hot spots*) y recopilar datos para apoyar la evaluación de instalaciones de energía renovable.

**Tecnologías:** ESP32-S3, cámara térmica, GPS, sensores ambientales e IoT.
